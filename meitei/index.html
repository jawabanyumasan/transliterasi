Mendukung C/Ca & Wignyan (H akhir) Otomatis

PANDUAN AKSARA

Vokal Jawa & Khusus:

  • é (taling) → ketik é (e.g. lélé)
  • ca / c → dipetakan ke ꯆ
  • h (akhir) → otomatis jadi Visarga ꫵ

Fitur Cerdas Otomatis:

CECAK (ng)

"mangan" → akhir kata otomatis menjadi ꯪ

WIGNYAN (h)

"gajah" → h di akhir otomatis menjadi ꫵ

CAKRA (r)

"kra" → otomatis menggunakan Virama ꯭ꯔ

LONSUM

Mendukung k, l, m, p, n, t di akhir suku kata.
