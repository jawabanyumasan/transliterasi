Latin Aksara Mro

Mro script adalah alfabet linear (seperti Latin), bukan abugida.

Panduan Transliterasi

Aturan Dasar

Aksara Mro tidak menggunakan pasangan atau sandhangan. Jika Anda menulis "KA", maka tulis huruf K (𖩌) lalu huruf A (𖩒).
Contoh: Kopi → 𖩌 (k) 𖩑 (o) 𖩐 (p) 𖩊 (i) = 𖩌𖩑𖩐𖩊.
