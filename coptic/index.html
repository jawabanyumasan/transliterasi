Panduan Transliterasi

1. Vokal & Bunyi Khusus Jawa

  • A → ⲁ (Alpha)
  • I → ⲓ (Iota)
  • U → ⲩ (Upsilon)
  • E (Pepet) → ⲉ (Epsilon)
  • É (Taling) → ⲏ (Eta)
  • O → ⲟ (Omicron)

2. Konsonan Utama

  • P → ⲡ (Pi)
  • S → ⲥ (Sigma)
  • T → ⲧ (Tau)
  • K → ⲕ (Kappa)
  • Th → ⲑ (Theta)
  • Dh → ⲇ (Delta)
  • Ng → ⲛⲅ
  • Ny → ⲛⲓ
  • C → ϭ (Shima)
  • J → ϫ (Ganjia)

3. Huruf Serapan & Angka

  • F → ϥ (Fei)
  • V → ⲃ
  • Kh → ⲭ (Khei)
  • Sy → ϣ (Shei)
  • Z → ⲍ (Zeta)
  • 1-9 → ⲁ, ⲃ, ⲅ, ⲇ, ⲉ, ⲋ, ⲍ, ⲏ, ⲑ
