Gunakan é untuk e-taling. Transliterasi mendukung Cecak (ng) dan Wignyan (h) otomatis.

Panduan Transliterasi

Aturan Akhiran (Final)

Cecak (Anusvara) dan Wignyan (Visarga) aktif untuk semua vokal:

  • king → किं (ki + ं)
  • kong → कों (ko + ं)
  • kuh → कुः (ku + ः)
  • kéh → कॆः (ké + ः)

Huruf Serapan

f → फ़ | q → क़ | z → ज़
kh → ख़ | sy → श | sh → ष

Medial (Cakra/Pengkal)

kra → क्र | kya → क्य
